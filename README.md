# Online Snack Shop Store (PHP & MySQL)

A full-stack e-commerce web application for browsing and purchasing snacks online, built with **PHP, MySQL, HTML, CSS, and JavaScript**.

## My Contributions (Core Modules)

1. Shopping Cart & Member Storefront
Product Browsing & Search - Implemented member-facing product listing, detailed product views, and keyword searching.
Cart & Checkout Workflow - Built interactive shopping cart functionality and order creation/checkout processing.

2. Order Maintenance (Member & Admin)
Customer Order Tracking - Developed member order history listing and detailed receipt/order views.
Admin Order Management - Created the administrative order dashboard for viewing all customer orders and inspecting order details.

3. Database & UI Design
Contributed to relational **MySQL** database schema design and responsive front-end interface development using **HTML5, CSS3, and JavaScript**.

---

## Team Project Features (Overall System Capabilities)
*As part of a collaborative team effort, the complete system also integrates the following modules developed by my teammates:*

4. Authentication & Security - Role-based access control (Admin & Member), secure login/logout, password hashing, and password reset workflows.

5. User & Member Management - Member registration, profile and password updates, profile photo uploads, and admin member directory with search.

6. Product Administration - Admin product catalog management (CRUD), product photo uploads, and inventory listing/searching.
